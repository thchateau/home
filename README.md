# Site personnel de Thierry Chateau

Ce dépôt contient un site statique, sans dépendance, conçu pour GitHub Pages.

## Publication avec GitHub Pages

1. Créez un dépôt GitHub et envoyez-y ces fichiers.
2. Dans **Settings > Pages**, sélectionnez **Deploy from a branch**.
3. Sélectionnez la branche `main` (ou `master`) et le dossier `/ (root)`.
4. Enregistrez : GitHub affichera l'adresse publique du site.

Le site est servi depuis `index.html`. Les contenus et liens professionnels sont directement modifiables dans ce fichier.
